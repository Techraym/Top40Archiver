# Top40Archiver 1.11.3

Datum: 2026-08-06

## Toegevoegd

- Permanente registratie van afgekeurde en mislukte downloads.
- SQLite-tabel `download_rejection_log` met artiest, titel, status, pogingsteller, zoekopdracht, bron-URL, tijdstip en volledige technische reden.
- Leesbaar JSONL-log in `/var/lib/top40-archiver/download-rejections.jsonl`.
- Automatische indeling van afkeuringsredenen, waaronder `youtube_bot_check`, `low_match_score`, `no_search_results`, `rate_limit`, `timeout`, `network` en `other`.
- Hulpscript `scripts/show-download-rejections.sh` voor het bekijken van recente afwijzingen.
- Eenmalige import van reeds bestaande `failed`- en `unavailable`-records tijdens installatie van de logfunctie.

## Gewijzigd

- De afkeurregistratie is fail-open: een fout bij het schrijven van het log stopt de downloader niet.
- De downloadworker kan veilig op één actieve worker worden ingesteld om opeenvolgende YouTube-blokkades te beperken.

## Installatie bestaande systemen

```bash
cd /opt/top40-archiver
sudo wget -O scripts/add-download-rejection-log.sh \
  https://raw.githubusercontent.com/Techraym/Top40Archiver/main/scripts/add-download-rejection-log.sh
sudo chmod +x scripts/add-download-rejection-log.sh
sudo ./scripts/add-download-rejection-log.sh
```

## Log bekijken

```bash
/opt/top40-archiver/scripts/show-download-rejections.sh 50
```

Samenvatting per reden:

```bash
sudo -u top40archiver sqlite3 -header -column \
  /var/lib/top40-archiver/top40.sqlite3 "
SELECT category AS reden, COUNT(*) AS aantal
FROM download_rejection_log
GROUP BY category
ORDER BY aantal DESC;
"
```

## Bekende beperking

YouTube kan downloads zonder browsercookies blokkeren met `Sign in to confirm you’re not a bot`. Deze versie registreert dergelijke afwijzingen afzonderlijk als `youtube_bot_check`, maar omzeilt de blokkering niet.
